## Finalidad
Punto de entrada del ecosistema Pokémon TCG Clone. Permite: (a) elegir a qué **herramienta/superficie**
entrar (Developer Studio, juego/launcher del cliente, Card Viewer, herramientas internas), (b) retomar
lo reciente (proyectos/sesiones), y (c) llegar a Ajustes globales. No edita contenido: **enruta**. Es
la única pantalla en tema "launcher" (no comparte el Shell de Z1–Z12 del Studio).

## Layout
Ventana de nivel superior (`WindowStyle` como marco de aplicación, sin scrim: es la raíz, no un modal
sobre otra cosa) dividida en tres franjas verticales:

```
┌───────────────────────────────────────────────────────────────┐
│ Z-A  Cabecera (Toolbar)                                        │  ← identidad + búsqueda + Ajustes
├──────────────┬────────────────────────────────────────────────┤
│ Z-B          │ Z-C  Contenido principal (ScrollArea)           │
│ Sidebar      │  ├ Sección "Herramientas"  (grid de Panel)      │
│ (secciones)  │  └ Sección "Reciente"      (ListView)           │
│              │                                                 │
├──────────────┴────────────────────────────────────────────────┤
│ Z-D  StatusBar (versión, estado de red/actualización)         │
└───────────────────────────────────────────────────────────────┘
```

Rejilla base 4dp; márgenes/gutter de `StudioSpacingTokens.Layout`; ancho de lectura limitado en las
descripciones (`ReadingMaxWidth`).

## Zonas
- **Z-A — Cabecera:** `ToolbarStyle`. Contiene: título de identidad (tipografía `Display`/`Title` vía
  contenido, sin componente nuevo), `SearchFieldStyle` (filtra herramientas/recientes), `IconButtonStyle`
  (Ajustes → 11.12) y `Badge` de novedades de versión.
- **Z-B — Sidebar de secciones:** `SidebarStyle`. Filas (`NavItemStyle`): "Herramientas", "Reciente",
  "Aprender/Docs", "Novedades". Selección única con barra guía `selectionEdge`.
- **Z-C — Contenido:** `ScrollAreaStyle` que aloja:
  - *Herramientas*: rejilla de **tarjetas de herramienta** = `PanelStyle` (cada tile: encabezado con
    título `Title`, descripción `Body`, `Badge` de estado "Instalado/Actualizar", y `ButtonStyle`
    `Primary` "Abrir"). La tarjeta de herramienta se **compone** de Panel + controles (no es componente
    nuevo).
  - *Reciente*: `ListViewStyle` + `ListRowStyle` (icono + nombre de proyecto + `Caption` de ruta/fecha +
    `IconButtonStyle` de menú `…`). Fila seleccionable; doble activación abre.
  - Vacío (sin recientes / sin resultados de búsqueda): `EmptyStateStyle`.
  - Carga inicial del catálogo: `SkeletonStyle` en los tiles / `LoadingPlaceholderStyle`.
- **Z-D — StatusBar:** `StatusBarStyle`. Segmentos (`Status`): versión del ecosistema, estado de
  actualización (tono `BadgeStyle.Tone`), conectividad. No interactivo salvo un segmento accionable.

## Componentes utilizados (todos existentes)
`WindowStyle` · `ToolbarStyle` · `SidebarStyle` · `ScrollAreaStyle`/`ScrollbarStyle` · `PanelStyle` ·
`ButtonStyle` (Primary/Neutral/Ghost) · `IconButtonStyle` · `SearchFieldStyle` · `BadgeStyle` ·
`ChipStyle` (filtros de catálogo) · `ListViewStyle`/`ListRowStyle` · `EmptyStateStyle` ·
`LoadingPlaceholderStyle`/`SkeletonStyle` · `MenuStyle`/`ContextMenuStyle` (menú `…` de un reciente) ·
`TooltipStyle` · `ConfirmationDialogStyle` (quitar reciente) · `SnackbarStyle`/`ToastStyle` (resultado
de acción) · `DividerStyle` · `StatusBarStyle`.

## Jerarquía (visual y de foco)
1. Herramienta primaria (tile "Developer Studio", acción `Primary`) — protagonista.
2. Otras herramientas (tiles secundarios).
3. Reciente (acceso rápido).
4. Cabecera (búsqueda/ajustes) y StatusBar (residual, `contentMuted`).
El chasis reposa; solo selección/foco suben contraste (VG-K).

## Flujo del usuario
1. Abre el ejecutable → Launcher carga catálogo (Skeleton → tiles).
2. Elige sección en la Sidebar **o** teclea en la búsqueda (filtra tiles + recientes en vivo).
3. Activa un tile "Abrir" → transición a la superficie elegida (p. ej. Project Selector 11.2 del Studio).
4. O activa un reciente → abre directamente ese proyecto en su editor.
5. `…` en un reciente → `MenuStyle` (Abrir, Abrir ubicación, Quitar de recientes → `ConfirmationDialog`).
6. Ajustes → 11.12.

## Navegación
- **Entra** desde el arranque del sistema.
- **Sale hacia:** Project Selector (11.2) / editor concreto (recientes) / Settings (11.12).
- Sidebar cambia de sección **dentro** del Launcher (no navega fuera).
- Sin breadcrumb (nivel raíz).

## Estados
- **rest / hover / pressed / selected:** tiles (Panel) y filas (ListRow) según sus `ComponentStyle`.
- **focus:** anillo único (`StudioFocusRing`) en tile/fila/control activo.
- **disabled:** herramienta no disponible en la plataforma → tile con contenido `contentDisabled` +
  Badge "No disponible"; su `Button` en estado `Disabled`.
- **loading:** Skeleton en tiles / LoadingPlaceholder mientras se resuelve el catálogo.
- **empty:** EmptyState (sin recientes; o búsqueda sin resultados con acción "Limpiar filtro").
- **error:** fallo de catálogo/red → EmptyState en tono de error + `SnackbarStyle`/`ToastStyle`
  (Danger); acción de reintento (`Button` Neutral).

## Accesibilidad
- Contraste reservado; texto residual (StatusBar) mínimo `contentMuted` sobre panel (≥ mínimo legible).
- Estado nunca solo por color: Badge de estado con texto; disabled con etiqueta.
- Foco visible único en todo elemento interactivo; orden de foco = orden visual (Cabecera → Sidebar →
  Contenido → StatusBar).
- Tooltips informativos (no esenciales); acciones alcanzables sin puntero.

## Comportamiento con teclado
- `Tab`/`Shift+Tab`: recorre zonas en orden visual.
- Sidebar: `↑/↓` cambian sección; `Enter` la activa.
- Contenido: `↑/↓/←/→` navegan la rejilla de tiles / la lista de recientes; `Enter` abre; `Space`
  selecciona; `F2`/`Menu` abre el menú contextual del reciente enfocado.
- Búsqueda: foco directo con atajo global (Command Palette NO se usa aquí; el Launcher usa búsqueda de
  campo simple); `Esc` limpia el filtro.
- `Esc` en un `ConfirmationDialog` cancela; acciones de teclado no se animan.

## Reglas de composición
- La "tarjeta de herramienta" y la "tarjeta de proyecto" se componen de `PanelStyle` + controles: **no**
  se introduce un componente Card nuevo.
- Un solo `Primary` por tile (la acción "Abrir"); el resto Neutral/Ghost.
- Feedback de acción → Snackbar/Toast (Notification), nunca Dialog salvo confirmación destructiva.
- Launcher NO usa el Shell del Studio (Dock/Inspector/Timeline/Preview): es superficie de enrutado.

## Restricciones
- Sin scrim en el `WindowStyle` raíz (no es modal).
- Sin Command Palette (pertenece al Workspace del Studio, 11.4), sin Breadcrumb (nivel raíz).
- Densidad `Comfortable`; una sola columna de lectura para descripciones.
