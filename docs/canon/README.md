# Canon del Proyecto — Pokémon TCG Clone

Documentación canónica oficial (Nivel I–II). La **Fase 0** es la máxima autoridad
normativa del proyecto: toda decisión de diseño o implementación debe ser
compatible con ella o modificarla mediante el procedimiento oficial de revisión
del Canon. En caso de conflicto entre documentos, **prevalece la Fase 0**.

Este directorio traslada el Canon al repositorio para cumplir las decisiones
**0.09 (Jerarquía Documental)**, **0.14 (Documentación Integral)** y
**0.20 (Trazabilidad Completa del Canon)**: el conocimiento fundacional queda
versionado, trazable y preservado junto al código.

## Jerarquía documental (Dec. 0.09)

- **Nivel I — Canon Fundacional**: `fase-00-canon-del-proyecto.md`.
- **Nivel II — Documentos Canónicos**: fases 01–10.
- **Nivel III** — Documentación arquitectónica/técnica (código y `/docs`).
- **Nivel IV** — Documentación operativa e histórica (auditorías, napkin).
