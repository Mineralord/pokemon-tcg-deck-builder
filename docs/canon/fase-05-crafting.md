DOCUMENTO CANÓNICO 

FASE 5 — SISTEMA DE FABRICACIÓN (CRAFTING) 

Capítulo I — Filosofía del Sistema de Crafting 

Edición Definitiva 

- 1.1 Propósito del Sistema 

- 1.2 El Sistema de Fabricación (Crafting) constituye el mecanismo permanente que permite a los jugadores obtener cartas específicas mediante el uso de Fichas. 

Su objetivo no es sustituir al sistema de obtención de cartas mediante sobres, sino complementarlo, garantizando que ningún jugador quede bloqueado indefinidamente por el azar y que toda carta oficial del Pokémon TCG permanezca accesible a largo plazo. 

El Crafting representa el principal mecanismo de preservación activa de la colección histórica del proyecto. 

- 1.3 Papel dentro de la Economía del Juego 

- 1.4 Dentro de la economía general de POKÉMON TCG CLONE: 

Los sobres continúan siendo el método principal para ampliar la colección. 

El Crafting actúa como un sistema complementario destinado a obtener cartas concretas. 

Las Fichas constituyen el único recurso utilizado para fabricar cartas. 

La economía del Crafting permanece completamente integrada con la economía principal del proyecto. 

En ningún caso el Sistema de Crafting sustituirá la importancia de abrir sobres. 

# 1.3 Principios Fundamentales 

Todo el Sistema de Crafting deberá respetar permanentemente los siguientes principios: 

Preservación absoluta de todas las cartas oficiales. 

Fidelidad al Pokémon TCG oficial. 

Compatibilidad histórica entre todas las expansiones. 

Libertad del jugador. 

Coleccionismo permanente. 

Progresión continua. 

Diversión por encima de restricciones artificiales. 

Evolución perpetua del sistema. 

Compatibilidad retroactiva. 

Inmortalidad del proyecto. 

Cualquier modificación futura deberá respetar estos principios. 

- 1.5 Filosofía de Acceso 

- 1.6 El Sistema de Crafting estará disponible para todos los jugadores desde el inicio del juego, una vez completado el tutorial inicial. 

No existirán desbloqueos mediante niveles, misiones, progreso, temporadas ni requisitos similares. 

El único requisito para fabricar una carta será disponer de las Fichas necesarias. 

1.5 Filosofía de Preservación 

Toda carta oficial incorporada al proyecto podrá fabricarse permanentemente. 

La desaparición de: 

Eventos, 

Promociones, 

Expansiones, 

Temporadas, 

Productos físicos, 

No eliminará nunca la posibilidad de fabricar dichas cartas. 

De esta forma el proyecto garantiza la preservación permanente de toda la historia del Pokémon TCG. 

- 1.7 Filosofía del Coleccionismo 

- 1.8 El Sistema de Crafting preservará tanto la jugabilidad como el coleccionismo. 

Todas las variantes oficiales de una carta podrán fabricarse individualmente. 

Cada variante constituirá una pieza independiente de la colección. 

Sin embargo, para construir barajas bastará con poseer cualquier variante oficial de la carta correspondiente. 

De esta forma se separan claramente dos conceptos: 

Colección. 

Jugabilidad. 

Esta separación constituye uno de los principios fundamentales del proyecto. 

1.7 Filosofía Económica 

Toda la economía del Sistema de Crafting se construye sobre una única regla: 

La rareza oficial del Pokémon TCG constituye el único parámetro económico del sistema. 

No influirán: 

Popularidad, 

Metajuego, 

Demanda, 

Antigüedad, 

Expansión, 

Precio de mercado, 

Ni ningún otro factor externo. 

La rareza oficial determinará: 

El costo de fabricación, 

La cantidad de Fichas obtenidas mediante duplicados, 

Y la posición económica de cada carta dentro del sistema. 

1.9 Economía Universal 

1.10 El Sistema de Crafting utilizará una única economía universal para toda la historia del Pokémon TCG. 

No existirán tablas económicas distintas para generaciones, bloques o eras. 

Toda nueva rareza oficial será incorporada mediante una actualización del Canon del proyecto, conservando la coherencia de la economía existente. 

# 1.9 Filosofía de Escalabilidad 

El Sistema de Crafting ha sido diseñado para mantenerse vigente durante décadas. 

Su arquitectura permitirá incorporar: 

Nuevas expansiones, 

Nuevas rarezas, 

Nuevas variantes, 

Nuevas mecánicas, 

Sin modificar las reglas fundamentales del sistema. 

La economía crecerá junto con el Pokémon TCG sin perder compatibilidad con el contenido histórico. 

- 1.11 Principio Rector del Sistema 

- 1.12 El Sistema de Crafting se rige por el siguiente principio permanente: 

El azar constituye un medio para acelerar el progreso del jugador, pero nunca será una barrera permanente para acceder a una carta oficial. 

Los sobres seguirán siendo la fuente principal de obtención de cartas. 

El Crafting garantizará que cualquier carta oficial pueda obtenerse mediante planificación, dedicación y administración de recursos, preservando al mismo tiempo el valor del coleccionismo y la emoción de abrir sobres.

Capítulo II — Funcionamiento General del Sistema 

Edición Definitiva 

# 2.1 Disponibilidad del Sistema 

El Sistema de Crafting estará disponible para todos los jugadores desde el inicio del juego, una vez completado el tutorial inicial. 

No existirá ningún sistema de desbloqueo mediante: 

Nivel de cuenta. 

Misiones. 

Progreso. 

Temporadas. 

Eventos. 

Modos de juego. 

El acceso al sistema será permanente. 

2.2 Recurso de Fabricación 

Todas las operaciones del Sistema de Crafting utilizarán exclusivamente Fichas. 

No existirán: 

Materiales de fabricación. 

Fragmentos. 

Recursos por expansión. 

Monedas especiales. 

Objetos consumibles adicionales. 

Las Fichas constituyen el único recurso económico necesario para fabricar cartas. 

2.3 Método de Fabricación 

La fabricación será directa. 

El jugador seleccionará una carta, el sistema mostrará: 

El costo en Fichas. 

La cantidad a fabricar. 

El costo total. 

Tras la confirmación, la carta se incorporará inmediatamente a la colección. 

No existirán: 

Tiempos de espera. 

Procesos de creación. 

Materiales secundarios. 

Probabilidades de éxito. 

Etapas intermedias. 

# 2.4 Fabricación Múltiple 

El jugador podrá fabricar varias copias de una misma carta en una única operación. 

El sistema permitirá seleccionar la cantidad deseada hasta alcanzar el límite máximo permitido para la colección. 

El costo total será calculado automáticamente antes de confirmar la operación. 

# 2.5 Acceso al Crafting 

El Sistema de Crafting estará integrado en toda la interfaz del juego. 

Siempre que una carta sea fabricable y el jugador aún no haya alcanzado el límite máximo de copias permitidas, aparecerá la opción Fabricar. 

Esta opción podrá mostrarse desde: 

La colección. 

El Deck Builder. 

El Museo. 

El buscador. 

Las expansiones. 

Las listas de cartas. 

Cualquier otra pantalla donde se visualicen cartas. 

No existirá un menú exclusivo obligatorio para acceder al Crafting. 

2.6 Restricciones de Fabricación 

El único requisito para fabricar una carta será disponer de las Fichas necesarias. 

No existirán requisitos relacionados con: 

Haber obtenido previamente la carta. 

Haber abierto sobres de su expansión. 

Haber descubierto la carta. 

Haber participado en eventos. 

Haber alcanzado un nivel específico. 

Toda carta oficial podrá fabricarse desde el momento en que esté incorporada al juego. 

# 2.7 Límites de Colección 

El Sistema de Crafting respetará los límites oficiales de posesión establecidos por el Pokémon TCG. 

Como norma general: 

Hasta cuatro copias de una carta normal. 

Los límites específicos establecidos oficialmente para cartas con restricciones especiales. 

Energías Básicas sin límite. 

El Sistema de Crafting comprobará siempre la colección del jugador antes de iniciar una fabricación. 

Si el jugador ya posee el número máximo permitido de copias de una carta o variante, la opción Fabricar permanecerá deshabilitada o no estará disponible. 

En consecuencia, el Sistema de Crafting nunca permitirá fabricar una carta que exceda el límite máximo de la colección. 

# 2.8 Construcción de Barajas 

La colección funcionará como una biblioteca permanente. 

Las cartas no quedarán asignadas ni bloqueadas por una baraja específica. 

Si el jugador posee el número máximo permitido de una carta, podrá utilizar esas mismas copias para construir cualquier cantidad de barajas de manera simultánea. 

No será necesario obtener copias adicionales para utilizar una carta en varios mazos. 

# 2.9 Variantes de Cartas 

Todas las variantes oficiales de una carta serán fabricables de forma independiente. 

Cada variante conservará: 

Su ilustración. 

Su rareza. 

Su identidad histórica. 

Su registro dentro del Museo. 

Sin embargo, para efectos de juego, bastará con poseer cualquier variante oficial de una carta para poder utilizarla en la construcción de barajas. 

# 2.10 Selección de Variantes 

El sistema dispondrá de un mecanismo híbrido para la selección de variantes. 

Cada carta podrá tener: 

Una variante favorita global. 

Una variante específica para cada baraja. 

La variante favorita será utilizada automáticamente al añadir una carta a un mazo. 

Cada baraja podrá sobrescribir dicha selección sin modificar la configuración global del jugador. 

# 2.11 Disponibilidad Permanente 

Toda carta oficial incorporada al proyecto permanecerá fabricable de manera permanente. 

La finalización de: 

Eventos. 

Promociones. 

Expansiones. 

Productos físicos. 

Temporadas. 

No eliminará nunca la posibilidad de fabricar dichas cartas. 

La única condición será: 

Disponer de las Fichas necesarias. 

No haber alcanzado el límite máximo permitido de copias en la colección. 

Cuando una carta sea obtenida mediante un sistema de obtención (como sobres, recompensas, eventos, PvE, PvP o futuros sistemas oficiales) y el jugador ya posea el máximo permitido de copias, dicha carta no se añadirá a la colección. En su lugar, será convertida automáticamente en la cantidad correspondiente de Fichas establecida en la Tabla Oficial de Conversión. 

Esta conversión automática nunca podrá producirse como resultado de una fabricación, ya que el Sistema de Crafting impedirá fabricar cartas cuyo límite de colección ya haya sido alcanzado.

# 3.1 Principios Económicos 

La economía del Sistema de Crafting constituye un subsistema permanente de la economía general de POKÉMON TCG CLONE. 

Su diseño responde a los siguientes principios: 

Simplicidad. 

Permanencia. 

Escalabilidad. 

Compatibilidad histórica. 

Objetividad. 

Facilidad de mantenimiento. 

Toda modificación futura deberá respetar estos principios. 

# 3.2 Unidad Económica 

La unidad económica del Sistema de Crafting son las Fichas. 

Las Fichas constituyen el único recurso utilizado para: 

Fabricar cartas. 

Convertir automáticamente duplicados. 

Gestionar la economía del Crafting. 

No existirán materiales adicionales ni recursos específicos por expansión. 

3.3 Escala Económica Universal 

Toda la economía del Crafting se basa en una única jerarquía económica universal. 

Esta jerarquía será válida para toda la historia del Pokémon TCG. 

Las equivalencias económicas no modifican la rareza oficial de una carta. 

Únicamente determinan: 

Su costo de fabricación. 

Su valor de conversión automática en Fichas.

3.6 Exclusión del Sistema de Fabricación 

La conversión automática de duplicados nunca se aplicará a cartas obtenidas mediante el Sistema de Crafting. 

Antes de iniciar cualquier fabricación, el sistema comprobará la cantidad de copias que posee el jugador. 

Si ya se ha alcanzado el límite máximo permitido para esa carta o variante, la opción Fabricar permanecerá deshabilitada o no estará disponible. 

Como consecuencia: 

El Sistema de Crafting nunca permitirá fabricar cartas que vayan a convertirse inmediatamente en Fichas. 

Las Fichas nunca podrán utilizarse para generar un ciclo de fabricación y reciclaje. 

La conversión automática quedará reservada exclusivamente para los sistemas de obtención de cartas.

La tabla económica ha sido construida utilizando una progresión matemática constante. 

Los valores finales han sido ajustados mediante redondeo inteligente para obtener cifras claras, fáciles de recordar y sencillas de mantener.

# 3.9 Independencia Económica 

El costo de fabricación de una carta nunca dependerá de: 

Su popularidad. 

Su valor comercial. 

El metajuego. 

Su demanda. 

La antigüedad de la expansión. 

La disponibilidad de productos físicos. 

Eventos limitados. 

Promociones. 

El único criterio económico será el escalón oficial al que pertenezca dentro de la Jerarquía Económica Canónica. 

# 3.10 Economía Permanente 

La economía del Sistema de Crafting permanecerá estable durante toda la vida del proyecto. 

Las futuras expansiones no modificarán los costos existentes. 

Cuando aparezca una nueva rareza oficial, se añadirá un nuevo escalón económico o se integrará en uno existente mediante una actualización del Canon, sin alterar los valores previamente establecidos. 

# 3.11 Principio Rector de la Economía 

La economía del Sistema de Crafting se rige por el siguiente principio permanente: 

Los sobres constituyen el principal método de obtención de cartas. El Crafting representa un mecanismo permanente de apoyo que garantiza el acceso a cualquier carta oficial mediante planificación, dedicación y administración eficiente de Fichas, preservando al mismo tiempo el valor del coleccionismo y la emoción de abrir sobres. 

Capítulo IV — Integración del Sistema de Crafting 

Edición Definitiva 

# 4.1 Integración con la Colección 

El Sistema de Crafting forma parte integral de la colección del jugador. 

Toda carta fabricada será incorporada inmediatamente a la colección permanente. 

Las cartas obtenidas mediante fabricación serán indistinguibles, para efectos de juego y colección, de aquellas obtenidas mediante sobres u otros sistemas oficiales. 

El origen de obtención de una carta no modificará su funcionamiento, valor de colección ni su disponibilidad para construir barajas. 

# 4.2 Integración con el Deck Builder 

El Sistema de Crafting estará completamente integrado con el constructor de barajas. 

Cuando el jugador intente añadir una carta que aún no posee, el sistema podrá ofrecer directamente la opción de fabricarla. 

Si el jugador dispone de las Fichas necesarias y no ha alcanzado el límite máximo permitido de copias, la fabricación podrá realizarse sin abandonar el Deck Builder. 

Tras completarse la fabricación, la carta quedará disponible inmediatamente para incorporarse a la baraja. 

4.3 Integración con los Sobres 

Los sobres constituyen el principal método de obtención de cartas. 

El Sistema de Crafting no pretende sustituir la apertura de sobres, sino complementarla. 

Las cartas obtenidas mediante sobres podrán incorporarse directamente a la colección o, si exceden el límite máximo permitido, convertirse automáticamente en Fichas conforme a la Tabla Oficial de Conversión. 

De este modo, cada sobre abierto contribuirá simultáneamente al crecimiento de la colección y al progreso del Sistema de Crafting. 

# 4.4 Integración con la Economía General 

El Sistema de Crafting utiliza exclusivamente Fichas como recurso económico. 

Las demás monedas del proyecto conservarán sus funciones definidas en la Fase 2. 

No existirán conversiones directas entre Fichas y otras monedas del juego, salvo aquellas aprobadas expresamente por el Canon. 

Esta separación garantiza la estabilidad y el equilibrio de la economía general. 

# 4.5 Integración con el Museo 

El Museo registrará todas las variantes oficiales obtenidas por el jugador. 

Fabricar una carta añadirá esa variante al Museo de la misma forma que cualquier otro método de obtención. 

El origen de la carta no alterará su registro histórico ni su valor como pieza de colección. 

4.6 Integración con la Progresión 

El Sistema de Crafting podrá integrarse con futuros sistemas de progresión, incluyendo logros, desafíos y recompensas. 

Dichos sistemas podrán otorgar Fichas como recompensa, respetando siempre la economía definida en este Documento Canónico. 

La obtención de Fichas mediante progresión complementará, pero nunca sustituirá, la apertura de sobres. 

# 4.7 Integración con PvE y PvP 

Los modos PvE y PvP podrán conceder Fichas como parte de sus recompensas. 

La cantidad de Fichas obtenidas será determinada durante el diseño de las fases correspondientes y deberá respetar el equilibrio económico establecido en esta fase. 

El Sistema de Crafting permanecerá completamente compatible con todos los modos de juego presentes y futuros. 

# 4.8 Integración con el Sistema de Intercambios 

Cuando el Sistema de Intercambios sea incorporado al proyecto (Fase 11), funcionará de manera independiente al Sistema de Crafting. 

Las cartas recibidas mediante intercambios seguirán las mismas reglas que cualquier otro método de obtención: 

Si no exceden el límite de la colección, serán incorporadas normalmente. 

Si exceden el límite permitido, serán convertidas automáticamente en Fichas según la Tabla Oficial de Conversión. 

4.9 Compatibilidad con Futuras Expansiones 

Toda expansión oficial incorporada al proyecto será compatible con el Sistema de Crafting desde el momento de su implementación. 

Las nuevas cartas utilizarán automáticamente la Jerarquía Económica Canónica vigente. 

Si una expansión introduce una nueva rareza oficial, esta será evaluada e incorporada mediante una actualización del Canon, respetando la arquitectura económica existente. 

4.10 Principio Rector de Integración 

El Sistema de Crafting ha sido diseñado para integrarse de forma transparente con todos los sistemas presentes y futuros de POKÉMON TCG CLONE. 

Ningún sistema del juego podrá invalidar, sustituir o contradecir las reglas fundamentales del Crafting. 

Toda futura funcionalidad deberá adaptarse a la arquitectura definida en esta fase, garantizando la preservación permanente, la compatibilidad histórica y la coherencia económica del proyecto. 

# 5.1 Permanencia del Sistema 

El Sistema de Crafting constituye un sistema permanente de POKÉMON TCG CLONE. 

No podrá eliminarse, deshabilitarse ni sustituirse por otro sistema de fabricación que contradiga los principios establecidos en este Documento Canónico. 

Toda evolución futura deberá construirse sobre la arquitectura aquí definida. 

# 5.2 Compatibilidad Retroactiva 

Toda carta oficial incorporada al proyecto conservará permanentemente su compatibilidad con el Sistema de Crafting. 

La incorporación de nuevas expansiones, generaciones o mecánicas no afectará la posibilidad de fabricar cartas publicadas anteriormente. 

Del mismo modo, las cartas históricas continuarán siendo compatibles con las futuras actualizaciones del sistema. 

# 5.3 Incorporación de Nuevas Rarezas 

Cuando The Pokémon Company introduzca una nueva rareza oficial, esta no modificará automáticamente la economía del Sistema de Crafting. 

Antes de su incorporación deberán definirse: 

Su posición dentro de la Jerarquía Económica Canónica. 

Su equivalencia económica con rarezas históricas existentes o, en caso necesario, la creación de un nuevo escalón económico. 

Su costo oficial de fabricación. 

Su valor oficial de conversión en Fichas. 

Estas modificaciones deberán realizarse mediante una actualización formal del Canon del proyecto. 

# 5.4 Estabilidad Económica 

Los valores oficiales de fabricación y conversión constituyen la base permanente de la economía del Sistema de Crafting. 

No podrán modificarse debido a: 

Cambios en el metajuego. 

Popularidad de determinadas cartas. 

Variaciones del mercado físico. 

Disponibilidad de productos comerciales. 

Opiniones de la comunidad. 

Tendencias competitivas. 

Únicamente podrán revisarse cuando exista una modificación estructural aprobada del propio Sistema de Crafting. 

# 5.5 Neutralidad del Sistema 

El Sistema de Crafting permanecerá completamente neutral respecto al contenido del juego. 

No favorecerá: 

Una expansión sobre otra. 

Una generación sobre otra. 

Un formato de juego sobre otro. 

Una mecánica específica. 

Un tipo de carta concreto. 

Toda carta será tratada exclusivamente según su posición dentro de la Jerarquía Económica Canónica. 

# 5.6 Independencia Tecnológica 

La arquitectura del Sistema de Crafting será independiente de la plataforma tecnológica utilizada por el proyecto. 

Cambios en: 

Motor gráfico. 

Lenguaje de programación. 

Base de datos. 

Infraestructura de servidores. 

Interfaz de usuario. 

No modificarán las reglas fundamentales del sistema. 

5.7 Compatibilidad con la Filosofía del Proyecto 

Toda modificación futura deberá permanecer alineada con los principios establecidos en las fases anteriores, especialmente: 

Preservación absoluta. 

Fidelidad al Pokémon TCG oficial. 

Compatibilidad histórica. 

Libertad del jugador. 

Coleccionismo permanente. 

Progresión continua. 

Evolución perpetua. 

Compatibilidad retroactiva. 

Inmortalidad del proyecto. 

Si una modificación entra en conflicto con cualquiera de estos principios, deberá prevalecer el Canon del proyecto. 

5.8 Principio Rector de Preservación 

El Sistema de Crafting existe para garantizar que ninguna carta oficial del Pokémon TCG quede inaccesible con el paso del tiempo. 

La arquitectura del sistema ha sido diseñada para mantenerse vigente durante décadas, permitiendo incorporar nuevas expansiones, nuevas rarezas y nuevas mecánicas sin comprometer la estabilidad económica ni la preservación de la historia completa del Pokémon TCG. 

El Sistema de Crafting constituye uno de los pilares fundamentales para asegurar la inmortalidad de POKÉMON TCG CLONE como archivo jugable, coleccionable y permanentemente accesible.
